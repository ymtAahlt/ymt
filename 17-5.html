JavaScript 定时器

JavaScript 内置了两种定时器：setTimeout（单次延时执行）与 setInterval（周期性重复执行）。下面通过几个可交互的小演示直观展示它们的用法与区别。

概念对比

setInterval — 重复执行

每隔指定毫秒数执行一次回调函数，持续运行直到被清除。

let id = setInterval(fn, 1000);
// ...
clearInterval(id); // 停止

setTimeout — 延时一次

在指定毫秒数后仅执行一次回调函数，执行完就结束（除非递归自己再次调用）。

let id = setTimeout(fn, 2000);
// ...
clearTimeout(id); // 取消
